# Projeto Prático III - Espinato Tech

Site acadêmico criado do zero com HTML, CSS e JavaScript.

## Requisitos atendidos
- Aba de apresentação da empresa;
- Aba de produtos;
- 3 linhas de produtos;
- 4 produtos em cada linha (12 no total);
- Linha de comunicação com formulário;
- FAQ interativo;
- Logomarca própria;
- Layout responsivo;
- Código próprio, sem construtor de sites pronto.

## Publicação no GitHub Pages
1. Crie um repositório público chamado `projeto-pratico-iii`.
2. Envie `index.html`, `empresa.html`, `produtos.html`, `contato.html`, `faq.html` e a pasta `assets` para a raiz do repositório.
3. No GitHub, acesse **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch **main** e a pasta **/(root)** e salve.
6. Aguarde a publicação.

Para o usuário `jcespinato`, mantendo exatamente esse nome de repositório, o endereço esperado será:
`https://jcespinato.github.io/projeto-pratico-iii/`
